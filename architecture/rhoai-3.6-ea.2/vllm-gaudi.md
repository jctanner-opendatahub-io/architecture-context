## Purpose

**Short**: Provides the vLLM hardware-plugin integration needed to run large-language-model inference on Intel Gaudi HPUs.

**Detailed**: `vllm_gaudi` registers an HPU platform with vLLM and supplies Gaudi-specific platform selection, attention backends, operators, model integrations, quantization support, distributed communication, and KV-cache transfer paths. It is loaded through vLLM's plugin entry points rather than acting as an independent control-plane service.

The downstream container builds a RHEL/UBI-based Gaudi runtime, installs Habana Synapse and PyTorch artifacts, checks out vLLM and this plugin, and starts vLLM's OpenAI-compatible API server. The plugin therefore participates in the inference data plane while deployment, authentication, and tenant isolation are supplied by the consuming vLLM/platform deployment.

## Architectural Analysis

This is a library-plus-image component with a strong hardware boundary. The Python package is dynamically discovered by vLLM via `vllm.platform_plugins` and `vllm.general_plugins` entry points. Registration wires in HPU platform behavior and a broad set of custom operations and model handlers, including attention, MoE, LoRA, Mamba, FP8, GPTQ, AWQ, ModelOpt, and compressed-tensor paths.

The Konflux image uses a multi-stage build to assemble Habana drivers and libraries, PyTorch, vLLM, and the plugin into one runtime. It pins the configured vLLM/plugin release and stable vLLM commit inputs but clones source during the build. Distributed execution and optional NIXL KV-cache transfer are implemented in the plugin and depend on the runtime's device and communication stack.

The primary architectural risks are external dependency and build reproducibility: the image uses a non-AIPCC UBI base, public PyPI, EPEL/CentOS repositories, and a vendor Habana repository, with no repository lockfiles or Hermeto prefetch configuration identified. The Dockerfile also explicitly removes `openssl-fips-provider-so`; no application crypto implementation was found, but this build choice is significant for RHOAI FIPS posture.
