## Purpose

**Short**: Model Registry stores model, version, artifact, and serving metadata and exposes REST APIs, UI, catalog, and KServe integration for RHOAI workloads.

**Detailed**: The primary Go service exposes the Model Registry REST API on port 8080 and persists metadata in a configured MySQL or PostgreSQL datastore. Kustomize bases and overlays deploy the service, database options, Istio routing, and the optional Kubeflow-oriented UI. The BFF fronts registry and catalog APIs, propagating user or service-account authorization while checking namespace access through Kubernetes authorization APIs.

The controller watches KServe `InferenceService` objects. For model-registry-linked objects it resolves a registry service in the relevant namespace, creates or updates registry-side serving-environment and inference-service records, and adds a finalizer. An optional catalog service and an async-upload Job extend the component with model/MCP catalog discovery and signed model transfer between storage backends.

## Architectural Analysis

Model Registry is a coordinated set of deployable surfaces rather than one binary. The Go REST proxy is the persistence-facing core; the controller is a namespace-aware control-plane adapter; the BFF and UI provide user-facing access; and catalog/async-upload artifacts add separate data and transfer planes. This separation permits the controller and registry API to be deployed independently, but requires consistent namespace, authorization, and service-discovery configuration across overlays.

The RHOAI release build uses a dynamically linked Go build with `GOEXPERIMENT=strictfipsruntime`, CGO, and a UBI minimal PQC runtime image. The async-upload image uses the AIPCC CPU base and installs a pinned Python supply chain including signing and OpenSSL-related packages. The repository contains language lock files, but no RPM or Hermeto artifact lock files were found in the analyzed checkout; this leaves OS-package reproducibility dependent on the pinned base images and build environment.
