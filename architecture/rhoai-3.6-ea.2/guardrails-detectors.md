## Purpose

**Short**: Guardrails Detectors provides three specialized content detection microservices (regex-based built-in detectors, HuggingFace model classifiers, and LLM-as-Judge evaluators) that integrate with the FMS Guardrails Orchestrator to detect safety issues, PII, and content quality concerns in generative AI workflows.

**Detailed**: Guardrails Detectors is a suite of Python microservices that analyze text input and output in generative AI systems. The component supports three detector classes: built-in rule-based detections (regex, file-type validation, custom Python rules), HuggingFace-based classifiers for tasks like toxic content detection (compatible with GraniteForCausalLM and AutoModelForSequenceClassification), and LLM-as-Judge evaluations using vLLM for subjective metrics like safety, accuracy, and helpfulness. Each detector runs as an independent container exposing FastAPI endpoints and is deployable as a KServe ServingRuntime for model inference. The component is managed downstream (Red Hat Data Services) from upstream TrustyAI with a synchronized main branch.

## Architectural Analysis

Guardrails Detectors implements a pluggable detector architecture where each detector type (built-in, huggingface, llm_judge) extends a common base API contract. The microservices expose FastAPI/Starlette HTTP endpoints without authentication middleware—security relies on the consuming Guardrails Orchestrator to enforce access control. All three detectors run uvicorn with 1-4 worker processes on port 8000 (or 8080 for built-in), configured with Prometheus instrumentation for observability. The HuggingFace detector is optimized for GPU inference via KServe with 18–20 GiB memory allocations and a 1–2 CPU core reservation; the LLM Judge detector integrates vLLM for efficient LLM server communication. Built-in detectors are lightweight and suitable for sidecar or co-located deployment. All three detectors rely on Python FastAPI frameworks and leverage AIPCC base images for supply-chain hardening, enabling accelerator-aware builds (CPU, NVIDIA CUDA 12.9–13.2, AMD ROCm, Intel Gaudi, IBM Spyre).
