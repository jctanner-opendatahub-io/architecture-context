## Purpose

**Short**: Provides detector microservices for evaluating generated or user-provided text with built-in heuristics, Hugging Face models, and LLM-as-a-judge evaluation.

**Detailed**: The repository packages detector implementations for the FMS Guardrails Orchestrator. The built-in service exposes lightweight regex, custom-code, and file-type detectors; the Hugging Face service loads local Transformer models for sequence, token, or Granite causal-language classification; and the LLM-judge service delegates evaluation to an OpenAI-compatible vLLM Judge endpoint.

The detector processes are FastAPI/uvicorn applications and are intended to run as KServe inference services. The supplied ServingRuntime resources are namespaced and single-model (`multiModel: false`). The Hugging Face example also supplies a model PVC, download init container, and MinIO service for model storage. Authentication and external ingress are delegated to the platform/KServe configuration rather than implemented by these applications.

## Architectural Analysis

This is a collection of stateless Python HTTP detector services with shared request/response schemas and instrumentation. Detector selection is implemented in application code: built-in detectors are registered during FastAPI lifespan startup, Hugging Face detects the local model architecture and chooses an appropriate Transformer class, and LLM Judge initializes from the required `VLLM_BASE_URL` environment variable.

The KServe integration is declarative rather than operator-based. Two namespaced `ServingRuntime` definitions advertise model formats and resource requirements, while example `InferenceService` objects enable platform authentication, Istio sidecar injection, and raw deployment mode. The repository does not define CRDs, controllers, Gateway API routes, or application RBAC roles.

The main architectural risks are deployment-example hygiene and explicit transport policy. The sample MinIO manifest includes placeholder access keys in pod environment variables and a statically provisioned opaque data-connection Secret; service authentication is enabled by annotations on the example InferenceServices, but the application endpoints themselves declare no auth mechanism. TLS settings are configurable through uvicorn but have no explicit minimum protocol or cipher policy in this checkout.
