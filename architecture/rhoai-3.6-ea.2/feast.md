## Purpose

**Short**: Feast is a feature store that manages feature definitions and serves low-latency online features for machine-learning workloads.

**Detailed**: The Feast operator reconciles namespaced `FeatureStore` resources into feature-store infrastructure. Depending on the CR specification, it creates registry, online-store, offline-store, UI, lineage, materialization, and transformation workloads, together with Services, PVCs, CronJobs, HPAs, ServiceMonitors, and RBAC.

The feature-server image packages the Feast Python server and its integrations. The Go serving implementation provides HTTP and gRPC online-feature serving, while the operator also supports Python feature-server deployments, remote registries, object stores, databases, Redis, notebook configuration, MLflow discovery, and OpenLineage integration.

## Architectural Analysis

Feast is a multi-artifact platform component rather than a single server. A namespaced `FeatureStore` is the control-plane contract; the operator translates that contract into independently configurable data-plane services and batch jobs. This allows registry, online serving, offline processing, UI, and lineage to be enabled selectively, but also means the effective architecture is determined by the CR and not solely by the operator installation manifests.

The RHOAI branch supplies separate Konflux images for the operator and Python feature server. RHOAI and ODH use the same kustomize composition with different target namespaces and CLI related images. Runtime TLS is configurable and OpenShift service-serving certificates can be applied automatically; the Go HTTP server explicitly requires TLS 1.2 or newer when TLS is enabled. The metrics monitor currently contains `insecureSkipVerify: true`, which is a deployment security gap unless replaced by the commented CA/certificate configuration.

The requested analyzer baseline was not present at `feast/.analyzer`; therefore this summary is source-derived and does not claim analyzer completeness. Dynamic resources created from `FeatureStore` specifications may exceed the static inventory below.
