## Purpose

**Short**: Training Hub provides a common Python interface for language-model fine-tuning, continual learning, reinforcement learning, prompt optimization, and embedding fine-tuning.

**Detailed**: The package presents stable, algorithm-oriented entry points such as `sft`, `osft`, `lora_sft`, `lora_grpo`, `grpo`, `gepa`, and `embedding_sft`. Its public API also includes callback normalization, reward functions, GPU-memory estimation, torchrun parameter handling, and loss visualization.

The implementation separates algorithm policy from execution through abstract `Algorithm` and `Backend` types and an `AlgorithmRegistry`. Backends adapt the public parameter model to InstructLab Training, RHAI Innovation Mini-Trainer, Unsloth/TRL, OpenPipe ART, verl, GEPA, MLflow, and SentenceTransformers. Training may run on one or multiple GPUs and nodes through torchrun/Accelerate; GEPA can instead call a hosted or local OpenAI-compatible LLM endpoint.

## Architectural Analysis

Training Hub is an orchestration and compatibility layer rather than a controller, serving runtime, or web service. The Strategy + Registry design allows one algorithm to select different execution backends while keeping user-facing calls consistent. The package includes adapters for backend-specific callback and context formats, which reduces coupling between training frameworks but makes dependency and version compatibility a significant operational concern.

The primary data path is local model/data input into a selected training backend, producing checkpoints, metrics, and optionally experiment-tracking records. Distributed execution is configured through validated function arguments and `PET_*`/standard torchrun environment variables. Optional integrations include MLflow and Weights & Biases tracking, OpenPipe ART, remote/local LLM APIs through LiteLLM, and Hugging Face model and dataset tooling.

The repository contains no deployment manifests or container build definitions. It therefore does not itself define Kubernetes availability, ingress, RBAC, tenant isolation, probes, or service ports; those properties belong to the consuming training job and platform deployment.
