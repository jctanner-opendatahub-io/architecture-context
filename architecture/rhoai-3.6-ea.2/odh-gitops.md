## Purpose

**Short**: Provides repeatable Kustomize and Helm-based installation and configuration of OpenDataHub/RHOAI platform dependencies.

**Detailed**: This repository is an administrator-owned deployment source of truth. Its Kustomize tree installs optional dependency operators through OLM and applies the corresponding cluster configuration resources. The default dependency set includes cert-manager, Kueue, Cluster Observability, OpenTelemetry, Leader Worker Set, JobSet, Tempo, Custom Metrics Autoscaler, and Red Hat Connectivity Link.

The charts provide an alternative Helm installation path for environments where OLM is unavailable, including dependency CRDs, operator workloads, post-install jobs, gateway resources, DataScienceCluster configuration, and optional cloud-manager resources. Installation can be composed in layers through Argo CD, Flux, `kubectl apply -k`, or Helm values/profiles.

## Architectural Analysis

This is a declarative orchestration repository, not a runtime service. The root Kustomization composes `dependencies/` and `configurations/`; dependency Kustomizations compose reusable operator Components, while configurations apply cluster-scoped CRs after the operators are installed. The repository consequently controls platform topology indirectly and delegates reconciliation to OLM-installed operators or Helm-rendered operator workloads.

The release branch supports two installation models: OLM subscriptions by default and Helm-managed dependency bundles when `install-with-helm-dependencies` is enabled. The Helm chart also uses post-install hooks to create DataScienceCluster/DSCInitialization and gateway-related resources. Argo CD users must account for CRDs that appear in a later sync phase (`SkipDryRunOnMissingResource=true`).
