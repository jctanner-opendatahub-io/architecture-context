## Purpose

**Short**: OpenVINO Model Server serves OpenVINO and supported framework models through REST and gRPC inference APIs.

**Detailed**: OVMS is a C++ inference server that loads models from a local model repository or supported remote storage and executes inference through OpenVINO. It exposes TensorFlow Serving, KServe, and generative/OpenAI-compatible interfaces, allowing clients to remain independent of model framework, hardware, and infrastructure.

In RHOAI, the repository supplies KServe runtime definitions that cause an inference service to run the OVMS image. The runtime definitions provide model-format selection, health probes, metrics annotations, model-path arguments, and CPU or GPU-oriented image choices; the KServe control plane supplies the surrounding workload and service resources.

## Architectural Analysis

OVMS is primarily a data-plane image rather than a Kubernetes control-plane component. Its container entrypoint is `/ovms/bin/ovms`; it does not define an operator, CRDs, RBAC, Services, Routes, or Deployments in this repository. KServe owns lifecycle and Kubernetes resource creation through the two supplied runtime definitions.

The server has separate REST and gRPC listeners and supports model management, health, metrics, streaming, and inference features in the application. The RHOAI runtime definitions select REST ports 8888 or 8080 and gRPC ports 8001 or 9000, while the upstream server defaults to unauthenticated/insecure gRPC unless TLS is configured externally or through another deployment layer. The optional `extras/nginx-mtls-auth` image provides an mTLS front proxy pattern, but it is not part of the KServe runtime definitions.

The Konflux build is a multi-stage C++/OpenVINO build based on UBI and emits a non-root runtime image using the UBI minimal PQC release base. It installs Python support and demo packages directly with pip, but does not use the AIPCC base-image ecosystem. OS and external source downloads are not fully locked in the checked-out branch, and the application uses MD5 for change detection rather than integrity/security decisions.
