## Purpose

**Short**: A controller-runtime module operator that reconciles the cluster-scoped `MCPLifecycleOperator` resource and deploys the MCP Lifecycle Operator operand. [source: cmd/main.go:90-150, internal/controller/mcplifecycleoperator_reconciler.go:108-217]

**Detailed**: This component implements the ODH/RHOAI module-operator pattern. It watches a singleton, cluster-scoped `MCPLifecycleOperator` custom resource, detects platform and TLS configuration, renders embedded operand manifests, and applies them with server-side apply. The managed operand is a separate controller that handles namespaced `MCPServer` resources.

The reconciler manages operand deployment, CRD, RBAC, Service, ServiceMonitor, and NetworkPolicy resources in `mcp-lifecycle-operator-system`. It tracks deployment readiness and updates platform-standard status and release conditions through `odh-platform-utilities`; a `Removed` management state triggers cleanup. [source: internal/controller/mcplifecycleoperator_reconciler.go:147-217, api/v1alpha1/mcplifecycleoperator_lifecycle.go:20-122]

## Architectural Analysis

The architecture has two controller tiers: this module operator owns the operand's installation and lifecycle, while the operand owns MCPServer workloads. Embedded YAML is loaded through an `embed.FS`, transformed with labels, namespace, image, and TLS environment variables, and deployed using an `odh-platform-utilities` SSA deployer with caching and apply ordering. [source: internal/controller/embed.go:1-10, internal/manifests/kustomize.go:38-78, cmd/main.go:118-126]

The module operator deliberately limits its cache to `SYSTEM_NAMESPACE` for namespaced objects and label-filters managed cluster-scoped roles, bindings, and CRDs. It uses leader election, non-root/read-only container settings, health probes, and operand readiness checks. Its broad cluster RBAC is consistent with lifecycle ownership but is a high-impact privilege surface.

TLS policy is fetched from the OpenShift `APIServer` resource when available, defaults to the Intermediate profile elsewhere, converts OpenSSL cipher names to IANA names, and injects `TLS_MIN_VERSION`, `TLS_CIPHER_SUITES`, `TLS_GROUPS`, and `PROPAGATE_TLS_ENV_VARS=true` into the operand Deployment. [source: internal/controller/tls.go:21-59, internal/manifests/kustomize.go:120-168]
