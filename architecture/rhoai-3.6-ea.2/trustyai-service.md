## Purpose

**Short**: TrustyAI Service ingests model inference data and exposes responsible-AI metrics, fairness analysis, drift detection, and explainability APIs.

**Detailed**: The service is a FastAPI application served by Hypercorn. It accepts KServe v2 inference payloads and KServe inference-logger CloudEvents, reconciles request/response pairs, stores inference data, and calculates metrics on a background schedule for Prometheus publication.

It supports local PVC/HDF5 storage by default and an optional MariaDB backend. Core routes cover data ingestion, metadata, health, metrics, and monitoring; fairness and drift routes are feature-flagged, while global and local explainers are disabled by default because they are experimental and computationally expensive. The container exposes a service path for kube-rbac-proxy and optional direct HTTPS, plus a separate health/consumer listener.

## Architectural Analysis

The application separates the FastAPI API surface from storage and metric implementations behind a global storage interface. This allows the same service process to use a filesystem-backed HDF5 store or MariaDB selected by `SERVICE_STORAGE_FORMAT`, with MariaDB dependencies loaded lazily only when that backend is requested.

The runtime uses two Hypercorn applications: the main API binds loopback HTTP for kube-rbac-proxy and can bind direct HTTPS when certificate files exist; a separate health application binds the health port and also receives KServe consumer traffic. Endpoint registration is centralized and controlled by environment-derived feature flags evaluated at import time. A background asyncio task periodically calculates and publishes Prometheus metrics and is cancelled during application shutdown.

The checkout contains application and container build sources but no Kubernetes deployment manifests, RBAC, or ingress definitions. Deployment security therefore depends on the consuming platform configuration. The source has no application authentication middleware and permits wildcard CORS, so an external enforcement point is important for production exposure.
