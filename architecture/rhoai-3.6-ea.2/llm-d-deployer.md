## Purpose

**Short**: Packages a monolithic Helm deployment for the llm-d distributed LLM inference stack and provides quickstart examples.

**Detailed**: The repository is a deployment and reference-architecture package, not a runtime service or controller implementation. Its main `llm-d` chart composes the ModelService API and controller deployment, inference gateway resources, model-serving presets, optional Redis, monitoring resources, and sample applications. Helm values select model artifacts, images, accelerators, scaling, networking, and observability behavior.

The repository also contains shell installers and example manifests for local and cluster-based use. The README marks the repository deprecated as of 2025-07-25 and directs new deployments to the more modular `llm-d-infra` Helmfile examples. Existing chart consumers may still use this repository as historical deployment data.

## Architectural Analysis

The chart is a meta-package whose rendered topology is conditional on values. A release can create the ModelService control-plane deployment, prefill/decode vLLM workloads, an inference gateway and HTTPRoutes, optional Redis, and monitoring objects. The `ModelService` CRD is namespaced, while several supporting RBAC objects are cluster-scoped and bind release service accounts.

The deployment boundary is the Helm release namespace. Inference traffic is routed through Gateway API resources when enabled; the quickstart Grafana path separately uses an OpenShift Route with edge TLS termination. The repository does not implement request authentication, tenant-aware data filtering, or network isolation itself, so those properties depend on the rendered downstream components and cluster policy.

This is a deprecated monolithic packaging model. Its external image references and chart dependencies are configurable and are not built or digest-pinned by this repository, leaving image provenance, FIPS posture, and much of the runtime security posture to the referenced images and the consuming platform.
