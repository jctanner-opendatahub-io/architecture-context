## Purpose

**Short**: Reconciles the cluster-scoped `AIGateway` resource and deploys the selected AI Gateway sub-component operators.

**Detailed**: `ai-gateway-operator` runs as an Open Data Hub module operator under `opendatahub-operator`. It watches the singleton `default-aigateway` custom resource, renders vendored Kustomize manifests, applies them through the Kubernetes API, and reports sub-component deployment readiness and release information back to the resource status.

The resource independently controls the `batch-gateway-operator` and Models as a Service (`maas-controller`) sub-components through `Managed`/`Removed` management states. The operator packages those manifests in its image, applies platform-specific namespaces and related-image parameters, and uses deployment readiness to aggregate module status. It does not itself serve model inference traffic; the enabled sub-components and their Gateway API resources provide that data plane.

## Architectural Analysis

This is a control-plane composition operator rather than an inference server. Its main architectural boundary is the `AIGateway` CR: a single cluster-scoped object selects which independently versioned operand operator manifests are installed. Kustomize rendering plus server-side apply makes the vendored manifests declarative and lets the module own the generated Deployments, CRDs, RBAC, Services, and webhooks.

The operator deliberately carries broad, cluster-level permissions because it installs operand CRDs and escalated operand RBAC. That is a significant trust boundary: compromise of the module service account can affect namespaces, workload deployments, Gateway API policy, secrets, and operand ClusterRoles. The implementation limits some cleanup operations with resource names, but the generated manager role still spans multiple platform APIs.

The analyzer reports no registered HTTP routes or ingress resources for this operator. Its 8443 Service is a metrics surface; Gateway API, TLS, tenant, and webhook resources are primarily operand manifests conditionally deployed by this controller. Webhook handler semantics and final rendered image substitutions remain partly unresolved in the analyzer baseline.
