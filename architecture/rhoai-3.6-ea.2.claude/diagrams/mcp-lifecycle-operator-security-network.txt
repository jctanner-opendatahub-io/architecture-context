RBAC Summary:

Manager Role (mcp-lifecycle-operator-manager-role):
  - Core API:
    - configmaps, secrets: get, list, watch
    - pods: get, list
    - services: create, get, list, update, watch
  - events.k8s.io:
    - events: create, patch
  - apps:
    - deployments: create, get, list, update, watch
  - mcp.x-k8s.io:
    - mcpservers: get, list, patch, update, watch
    - mcpservers/finalizers: update
    - mcpservers/status: get, patch, update
  - networking.k8s.io:
    - networkpolicies: create, get, list, update, watch

Metrics Auth Role (mcp-lifecycle-operator-metrics-auth-role):
  - authentication.k8s.io:
    - tokenreviews: create
  - authorization.k8s.io:
    - subjectaccessreviews: create

Aggregated Roles (RBAC aggregation to built-in roles):
  - mcpserver-admin-role: full CRUD + deletecollection on mcpservers
  - mcpserver-editor-role: CRUD on mcpservers (no deletecollection)
  - mcpserver-viewer-role: read-only on mcpservers

Leader Election Role (mcp-lifecycle-operator-leader-election-role):
  - Namespace-scoped (mcp-lifecycle-operator-system)
  - configmaps: full CRUD
  - coordination.k8s.io/leases: full CRUD
  - events: create, patch

Service Account Bindings:
  - SA: mcp-lifecycle-operator-controller-manager
    → mcp-lifecycle-operator-manager-role (ClusterRoleBinding)
    → mcp-lifecycle-operator-metrics-auth-role (ClusterRoleBinding)
    → mcp-lifecycle-operator-leader-election-role (RoleBinding, ns-scoped)

TLS Configuration:
  - Environment-driven: TLS_MIN_VERSION, TLS_CIPHER_SUITES
  - Controller-runtime self-signed certs for metrics (default)
  - Configurable cert paths: --metrics-cert-path, --webhook-cert-path
  - HTTP/2 disabled by default (CVE: GHSA-qppj-fm5r-hxr3, GHSA-4374-p667-p6c8)
  - FIPS: strictfipsruntime + OpenSSL via UBI9 base image

Secrets:
  - No explicitly provisioned secrets
  - Controller-runtime generates self-signed TLS certificates at runtime
