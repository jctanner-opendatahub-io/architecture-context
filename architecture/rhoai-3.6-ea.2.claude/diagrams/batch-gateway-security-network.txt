- Build flags: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1
- Linking: Dynamic (CGO) on UBI9 ubi-minimal base
- OpenSSL: Yes (via UBI9 base image)
- TLS Config: crypto/tls with configurable min version (default TLS 1.2)
- Cipher suites: Go-managed (FIPS-validated via OpenSSL with strictfipsruntime)
- ALPN: h2, http/1.1 (default)
- Certificate handling: X509 key pair from file paths, cert-manager integration
- Non-FIPS crypto risks: None detected

Authentication & Authorization Summary:
- API endpoints (/v1/batches, /v1/files):
  - No application-level auth enforcement
  - Authorization header captured and passed through to downstream inference
  - Authentication expected to be enforced by external platform gateway
  - Tenant identification via X-MaaS-Username header
- Observability endpoints (/health, /ready, /metrics):
  - No authentication
  - Runs on separate listener (port 8081, always plain HTTP)
  - No middleware applied

RBAC Summary:
- No ClusterRoles or RoleBindings defined in component manifests
- RBAC is expected to be managed externally or via operator

Secrets:
- No secrets explicitly defined in component manifests
- Runtime credentials for PostgreSQL, Redis, S3 expected via Helm values or environment

Network Listeners:
- 8000/TCP: API server (HTTP/HTTPS, optional TLS)
- 8081/TCP: Observability (always plain HTTP) - all three components
