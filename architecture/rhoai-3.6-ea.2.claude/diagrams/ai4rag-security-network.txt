SECURITY RISKS:
1. TLS Verification Bypass: MaaS client falls back to verify=False on SSL
   certificate verification failure. This disables all certificate validation
   and enables MITM attacks. (ai4rag/utils/clients/maas_client.py:56-62)

2. No FIPS Mode: No explicit FIPS crypto library usage. FIPS compliance
   depends entirely on host Python runtime and underlying TLS libraries.

3. Environment Variable Secrets: All credentials stored as plain environment
   variables with no encryption at rest or rotation mechanism.

RBAC Summary:
- No Kubernetes RBAC resources defined (pure Python library)
- No ServiceAccounts, ClusterRoles, or RoleBindings

Network Policy:
- No Kubernetes NetworkPolicy defined (no deployment manifests)
- Network controls are delegated to the consuming application's deployment
