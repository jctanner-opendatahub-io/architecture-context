  - configmaps, leases, events (leader election)

Authentication Modes (CRD-configurable):
1. Kubernetes RBAC: TokenReview validation against kube-apiserver
2. OIDC: JWT validation via pyjwt, Secret-referenced configuration
3. noAuth: Explicitly disabled (requires explicit opt-in)
   Note: Exactly one mode must be selected in FeatureStore CR AuthzConfig

Security Considerations:
- Go feature server has NO authentication interceptors (relies on network isolation)
- Python SDK enforces auth when SecurityManager is initialized
- Operator metrics endpoint enforces TokenReview + SubjectAccessReview
- Health probes (:8081) are unauthenticated by design
- FIPS: Operator built with strictfipsruntime, UBI9-pqc base image
- TLS profile delegated to OpenShift cluster configuration

Secrets:
- AWS_SECRET_ACCESS_KEY (env var) - S3 credentials, runtime environment provisioned
- AWS_SESSION_TOKEN (env var) - AWS session token, runtime environment provisioned
- FEAST_OIDC_TOKEN (env var) - OIDC token for auth, runtime environment provisioned
- FEAST_RAY_AUTH_TOKEN (env var) - Ray cluster auth, runtime environment provisioned
- LOCAL_K8S_TOKEN (env var) - Kubernetes token, runtime environment provisioned
- GITHUB_TOKEN (env var) - GitHub access, runtime environment provisioned
- VAULT_TOKEN (env var) - Vault access, runtime environment provisioned
