INBOUND TRAFFIC: NONE
- No HTTP/gRPC endpoints exposed
- No Kubernetes Services defined
- No Ingress/Route configured
- Component runs as a batch Job and exits after completion

RBAC Summary:
- No ClusterRoles or RoleBindings defined in this repository
- Kubernetes client library (kubernetes ==36.0.2) is a dependency,
  suggesting runtime RBAC is configured externally by the deploying operator

Crypto & TLS:
- cryptography ==49.0.0 (transitive, wraps OpenSSL)
- pyjwt ==2.13.0 (transitive, JWT validation)
- TLS configuration delegated to Python requests/httpx/boto3 defaults
- FIPS compliance depends on base container image OpenSSL configuration
- KFP client supports verify_ssl and ssl_ca_cert configuration overrides

Auth Resolution Chain (multi-tier):
1. Direct API key value from JobSpec
2. Named key from mounted model auth secret (evalhub.adapter.auth.read_model_auth_key)
3. Environment variable lookup
4. Role-convention key matching
5. "DUMMY" fallback (development mode)
