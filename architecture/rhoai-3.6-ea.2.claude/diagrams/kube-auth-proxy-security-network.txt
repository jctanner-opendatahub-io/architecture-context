OAuth2 Endpoints:
- /oauth2/sign_in   (GET) - Sign-in page rendering
- /oauth2/start     (GET) - Initiates OAuth2 authorization code flow
- /oauth2/callback  (GET) - OAuth2 authorization code callback (CSRF token)
- /oauth2/sign_out  (GET) - Session termination (session cookie required)
- /oauth2/userinfo  (GET) - Authenticated user info (session cookie required)
- /oauth2/auth      (GET) - Auth-only verification for ext_authz (session cookie)
- /ping             (GET) - Health check probe
- /robots.txt       (GET) - Robots exclusion

Secrets:
- kube-auth-proxy-secret (Opaque) - Cookie secret and client credentials
  - Provisioned by: manifest
  - Auto-rotate: Unknown

Authentication & Authorization:
- Kubernetes API: ServiceAccount token (in-cluster auto-mount)
  - Enforcement: kube-apiserver
- Token validation: Kubernetes TokenReview API
  - Enforcement: Application-level via kube-apiserver
- Proxied upstream: Multi-mechanism
  - OAuth2/OIDC session cookie
  - K8s ServiceAccount bearer token
  - JWT bearer token (configurable issuer)
  - Basic Auth (htpasswd)
  - Enforcement: OAuthProxy middleware chain
  - Configurable skip-auth routes and trusted IPs

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1 (dynamic linking)
- Base image: ubi9/ubi-minimal-pqc (post-quantum cryptography ready)
- TLS: crypto/tls with MinVersion 1.2, MaxVersion 1.3
- Cipher suites: Configurable, defaults to Go FIPS-approved set

Security Evidence:
- rbac-ref: NewTokenReviewValidator (token review call)
- rbac-ref: doTokenReview (token review call)
- rbac-ref: TokenReviews (token review call)
- tls-config: crypto/tls (TLS configuration import)
