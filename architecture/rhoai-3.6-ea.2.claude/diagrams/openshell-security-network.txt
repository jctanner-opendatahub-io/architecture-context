- {release}-credential-kek (Opaque) - AES-256-GCM KEK for credential encryption, Helm hook, no auto-rotation

FIPS Notes:
- TLS: rustls 0.23 + ring 0.17 (NOT routed through OpenSSL FIPS module)
- JWT: jsonwebtoken with aws_lc_rs (FIPS-validated variant available but not explicitly enabled)
- Build images include openssl-fips-provider but Rust runtime does not use it
- Application-level FIPS compliance NOT verified

Authentication Chain:
- OIDC (Keycloak): Bearer token → JWKS validation → workspace roles (user/admin)
- Sandbox JWT: Ed25519 signed by gateway → SPIFFE subject (spiffe://openshell/sandbox/{uuid})
- Compute Driver Bootstrap: one-time token → scoped to IssueSandboxToken RPC only
- Authorization: protobuf method annotations declare auth mode, scope, role per RPC
