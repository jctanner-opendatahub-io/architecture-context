SDK Authentication Model:
- The SDK performs NO authentication itself
- Authentication is fully delegated to the kubernetes Python client library
- Development: kube-config file (~/.kube/config) with x509 certs or OIDC tokens
- In-cluster: Mounted ServiceAccount token at /var/run/secrets/kubernetes.io/serviceaccount/token
- All TLS is platform-delegated (SDK does not configure TLS directly)

Secrets:
- HF_TOKEN (environment variable) - HuggingFace API token for model downloads
  - Provisioned by: runtime environment (user-provided)
  - Auto-rotate: Unknown

Security Evidence:
- cryptography==46.0.5: Transitive dependency via pygithub→pyjwt (not direct SDK usage)
- pyjwt==2.11.0: Transitive dependency via pygithub (development tooling, not SDK auth)
- kubernetes client: Handles all TLS and auth via platform OpenSSL

FIPS Compliance:
- Python SDK: No compiled binaries, no direct cryptographic operations
- TLS: Delegated to platform OpenSSL (FIPS-capable on RHEL/UBI)
- Risk: No explicit FIPS opt-in or provider selection in SDK source
