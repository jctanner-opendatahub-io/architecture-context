RBAC Summary:
  No explicit RBAC roles defined in odh-gitops itself.
  RBAC is delegated to each provisioned operator's own manifests.
  Cluster-admin privileges required at install time for Helm/Kustomize apply.

Authentication & Authorization:
  - Platform Services: Authorino (Kuadrant) provides cluster-wide authorization
    enforcement from the kuadrant-system namespace
  - Authorino listener: TLS-enabled via authorino-server-cert
  - Authorino OIDC server: TLS disabled (internal cluster use)

Secrets (Provisioned):
  - authorino-server-cert: TLS certificate for Authorino listener
    (provisioned by cert-manager)

TLS Configuration:
  - Authorino listener: TLS enabled (cert from cert-manager)
  - Authorino OIDC: TLS disabled
  - Optional tls-enabled overlay: Adds explicit TLS listener config
  - Sail/Istio (XKS): Provides mTLS between services

Deployment Targets:
  - OpenShift: Via OLM Subscriptions (operators from CatalogSource)
  - AWS EKS: Via rhai-on-xks-chart (Helm sub-charts)
  - Azure AKS: Via rhai-on-xks-chart (Helm sub-charts)
  - CoreWeave: Via rhai-on-xks-chart (Helm sub-charts)
