- Base image: registry.redhat.io/ubi9/ubi-minimal-pqc (UBI9 with PQC support)
- GRPC_PYTHON_BUILD_SYSTEM_OPENSSL=1 (gRPC uses system OpenSSL, not BoringSSL)
- Crypto: hashlib (SHA-256), secrets (constant-time) — both delegate to system OpenSSL
- TLS: Delegated to Python ssl module backed by system OpenSSL
- FIPS mode: Inherited from RHEL/OpenShift node (not explicitly enforced by app)
- No third-party crypto libraries for core functionality

Authentication Summary:
- HTTP API: Bearer token auth is OPT-IN (only active when VLLM_API_KEY or --api-key set)
- Guarded prefixes: /v1/*, /v2/*, /inference/*
- Unguarded: /health, /ready, /readyz, /load, /docs, /ping
- gRPC API: NO authentication (port 50051 is insecure)
- Token comparison: SHA-256 hashing with constant-time comparison (timing-attack resistant)
