Security Model (Split-Privilege Design):
- CONTROLLER (operator workstation):
  - Full cluster access via user's kubeconfig
  - Performs ALL Kubernetes API mutations
  - Runs outside the cluster
- AGENT (probe Job pods):
  - ZERO Kubernetes API permissions (empty ClusterRole rules)
  - Privileged SCC ONLY for host device access (/sys/class/*)
  - Cannot create, read, or modify any Kubernetes resources
  - Results returned via stdout (log API) and ConfigMaps (controller-created)
