RBAC Summary:
- No ClusterRoles or RoleBindings are defined in this repository
- RBAC is expected to be managed by the deploying operator (llm-d operator or RHOAI platform operator)

Authentication & Authorization:
- ExternalProcessor gRPC: No application-level auth; transport TLS is configuration-dependent
- Health gRPC: No application-level auth; transport TLS is configuration-dependent
- Metrics endpoint (EPP): Optional mTLS with client-certificate verification
  - Flags: --metrics-endpoint-auth, --metrics-client-ca-file
  - Default: Authentication disabled
- Kubernetes API: kubeconfig credential chain (ServiceAccount token)

FIPS Compliance:
- Build: GOEXPERIMENT=strictfipsruntime, CGO_ENABLED=1 (dynamic linking)
- Crypto: All operations routed through system OpenSSL via Go FIPS runtime
- Base Image: UBI9 PQC minimal (registry.redhat.io/ubi9/ubi-minimal-pqc)
- TLS Config: crypto/tls with configurable TLSMinVersion and TLSCipherSuites
- Certificate: File-based loading or self-signed RSA 4096-bit generation
- No non-FIPS crypto risks detected

Secrets:
- No secrets are defined in this repository
- Secret provisioning is expected to be managed by the deploying operator

Service Definitions:
- No Kubernetes Service manifests are shipped in this repository
- Services are managed by the deploying operator (llm-d operator or RHOAI platform operator)
