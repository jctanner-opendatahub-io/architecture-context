Port Summary:
  8443/TCP - kube-rbac-proxy external (TLS, authenticated)
  8081/TCP - Main API loopback (HTTP, pre-authenticated)
  8080/TCP - Health/Consumer API (HTTP, unauthenticated, internal)
  4443/TCP - Optional HTTPS listener (TLS, system crypto policy)
  3306/TCP - MariaDB (MySQL, optional TLS)

FIPS Compliance:
- TLS Configuration: PolicyAwareConfig delegates to ssl.create_default_context()
- Cipher Selection: System crypto policy (no application overrides)
- Crypto Libraries: Python stdlib ssl only; cryptography package explicitly removed
- Certificate Paths:
  - /etc/tls/internal/tls.crt (service TLS cert)
  - /etc/tls/internal/tls.key (service TLS key)
  - /etc/tls/db/ca.crt (MariaDB CA cert)

Secrets:
- DATABASE_PASSWORD (environment variable) - MariaDB credentials, runtime provisioned
- QUARKUS_DATASOURCE_PASSWORD (environment variable) - Legacy Quarkus-compat DB password, runtime provisioned

Authentication Summary:
  Main API (8081):        Platform-delegated via kube-rbac-proxy (Kubernetes RBAC)
  Health/Consumer (8080): Unauthenticated (kubelet probes, KServe, ModelMesh, Prometheus)
  HTTPS Listener (4443):  TLS client certificate (optional), system crypto policy
