RBAC Summary:
- No Kubernetes ClusterRoles or RoleBindings are defined by this component.
- Access control is delegated to the platform layer.

Authentication & Authorization:
- gRPC API: Optional mTLS via MetadataStoreServerConfig.SSLConfig
  - server_key: Server private key
  - server_cert: Server certificate
  - custom_ca: Custom CA certificate
  - client_verify: Enable client certificate verification (mTLS)
- No application-level authentication or authorization mechanism
- Auth enforcement is platform-delegated (e.g., Service Mesh, NetworkPolicy)

Secrets:
- No Kubernetes Secrets are defined by this component.
- Database credentials are provided via MetadataStoreServerConfig protobuf.
- TLS certificates are provided via SSLConfig protobuf fields.

Crypto & FIPS:
- C++ binary links against system OpenSSL (from openssl-devel at build time)
- Runtime crypto from UBI9 base image OpenSSL
- No explicit FIPS mode build flags or runtime configuration
- FIPS compliance depends on platform OpenSSL FIPS provider settings

Container Security:
- Base image: ubi9/ubi-minimal-pqc
- Runs as non-root user (UID 65534)
- Statically-linked C++ binary
- MariaDB client connector (libmysqlclient) bundled as third-party dependency
