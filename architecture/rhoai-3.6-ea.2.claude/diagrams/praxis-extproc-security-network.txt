TLS Configuration:
  - Provider: OpenSSL crate → system OpenSSL (UBI9)
  - Profile: SslAcceptor::mozilla_intermediate
  - ALPN: h2 negotiation
  - Modes: plaintext | self-signed ephemeral | provided cert/key | mTLS (CA cert)
  - DestinationRule: SIMPLE TLS with explicit SNI (Envoy → ExtProc)
  - FIPS: System OpenSSL on UBI9 supports FIPS when OS FIPS mode enabled
  - Risk: ring (non-FIPS) present in dependency tree via transitive deps
