FIPS Compliance:
- Build flags: GOFIPS140=v1.0.0, CGO_ENABLED=0, -tags no_openssl
- Linking: Static (CGO disabled, Go native FIPS 140-3 crypto module)
- OpenSSL: Not used; Go native FIPS 140-3 module via GOFIPS140
- Base image: ubi9/ubi-minimal-pqc (post-quantum cryptography support)
- TLS: crypto/tls via Go FIPS 140-3 module; grpc/credentials for gRPC TLS

Authentication & Authorization:
- /healthz (port 6060): No authentication (health probe only)
- Argo Server API (port 2746): Gatekeeper interceptor
  ├── Client mode: Bearer/Basic token forwarded → K8s API impersonation
  ├── Server mode: Uses argo-server ServiceAccount
  └── SSO mode: Validates OIDC token with optional RBAC delegation
      to namespace-scoped ServiceAccounts annotated with rule expressions

Security Evidence:
- TLS config: crypto/tls, google.golang.org/grpc/credentials
- RBAC ref: SelfSubjectAccessReviews (token/subject access review calls)
