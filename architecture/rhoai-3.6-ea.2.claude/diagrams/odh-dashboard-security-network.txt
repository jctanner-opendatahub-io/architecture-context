BFF Authentication Modes:
- user_token: Extracts Bearer token from Authorization header, forwards to K8s API
- internal: Uses pod ServiceAccount token for all K8s API calls
- disabled: Development mode, no authentication enforced

BFF Authorization Middleware:
- InjectRequestIdentity: Extracts and validates caller identity on /api/v1/*
- RequireAccessToService: Namespace-scoped RBAC check
- RequireAuthenticatedForAgents: SubjectAccessReview-based per-agent authorization
