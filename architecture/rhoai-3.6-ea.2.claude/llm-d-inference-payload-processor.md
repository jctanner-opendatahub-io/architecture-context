## Purpose

**Short**: llm-d-inference-payload-processor is an Envoy External Processor (ExtProc) service built on controller-runtime that intercepts and transforms LLM inference requests in the llm-d serving stack, providing pluggable request/response processing, model selection, and observability. **Detailed**: llm-d-inference-payload-processor implements the Envoy External Processing (ExtProc) gRPC API to intercept inference requests flowing through an Envoy proxy in the llm-d serving stack. It operates as a controller-runtime-managed service that receives per-request processing callouts from Envoy, applies a configurable pipeline of pre-processors (request mutation, header extraction, model selection) and post-processors (response mutation, metadata injection), and returns modified requests/responses to the proxy. The component defines a PayloadProcessorConfig CRD (llm-d.ai/v1alpha1) for declarative configuration and uses a plugin framework with in-tree plugins for body-field-to-header extraction, base-model resolution via ConfigMap reconciliation, model group filtering, scoring-based model selection (in-flight requests, session affinity, cost guard), and response header injection. It integrates with llm-d-router as a Go library dependency for shared plugin types. The service exposes three network ports: gRPC ExtProc on port 9004 (with optional self-signed TLS), gRPC health probes on port 9005 (plaintext), and Prometheus metrics on port 9090 (with optional Kubernetes TokenReview authentication).
