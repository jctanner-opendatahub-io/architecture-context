# Repo to Architecture Summary

Generate the markdown file defined by the --output= argument based on ${CLAUDE_SKILL_DIR}/templates/architecture-template.md

The --output= flag defines the -only file you should be writing to.

The [directory] argument defines the git repository checkout for the component you are analyzing to fill in the template.

Use the other skill arguments to fill out the template as needed.

Baseline facts about the repostiory are in json files under --analyzer-dir, which were generated by arch-analyzer to save you time and tokens.

Read any other files from the repository as needed. If README.md exists, determine if it has any useful content for the summary but do not let it override facts from arch-analyzer.

Prefer Dockerfiles with ,konflux filename suffixes over others.

## Arguments

- `[directory]` — repository path, default current directory.
- `--analyzer-dir=PATH` — directory containing the analyzer JSON, rendered
- `--distribution=odh|rhoai|both`, default `both`.
- `--output=PATH`, default `GENERATED_ARCHITECTURE.md` for standalone use.
- `--generated-by=STRING`, optional metadata value.
- `--component-name=STRING`, name of the component.
